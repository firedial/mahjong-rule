# mahjong-rule

## 概要

麻雀のルールセットを作るためのツール。

## ルール出展

らすかるの家で掲載されていたルールをもとに作成しています。
サイト自体は閉鎖済みのため、アーカイブからルールを取得しています。

https://web.archive.org/web/20250331131725/http://www10.plala.or.jp/rascalhp/

## バージョン管理

バッチバージョンは、文言修正など構造に影響を与えない修正の時に変える。
マイナーバージョンは、選択肢や子ルールの選択条件など構造に影響を与える時に変える。
メジャーバージョンは、大きな修正が入ったときに変える。

基本的にはメジャーバージョンを変えず、マイナーバージョン以下を変える。
