  • パッチ: 文言修正など構造に影響を与えない修正(例: 1.2.3 → 1.2.4)
  • マイナー: 選択肢や子ルールの選択条件など構造に影響を与える修正(例: 1.2.3 → 1.3.0)
  • メジャー: 後方互換性のない JSON 構造などの修正(例: 1.2.3 → 2.0.0)

基本的にはメジャーバージョンを変えず、マイナーバージョン以下を変えます。また、構造に影響を与えるルール変更は、別途ルール ID を再発行する運用にします。
